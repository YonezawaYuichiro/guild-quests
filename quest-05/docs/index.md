# starmap documentation

starmap reads the star catalogs of the Guild.

| Version | Documentation | Status |
| --- | --- | --- |
| 2.1 | [v2/](v2/quickstart.md) | Latest |
| 1.4 | [v1/](v1/quickstart.md) | Old. No longer updated. |

Which version do you have? Check it in Python:

    python -c "import starmap; print(starmap.__version__)"

Always read the documentation for **your** version.
Code from the documentation of another version may not work.
