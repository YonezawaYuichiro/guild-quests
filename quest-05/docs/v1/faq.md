# FAQ (starmap 1.4)

> **Note:** This is the documentation for starmap **1.4**.
> For the latest version, see [the 2.x documentation](../v2/faq.md).

## `search()` returns `None`. Why?

The star is not in the catalog. Check the spelling. Upper and lower case matter.

## Can I edit a catalog file by hand?

Please don't. The words of the stars are encoded.
